# Campus Update — Landing Page

Official landing page for **Campus Update**, built with React and Tailwind CSS to introduce the platform, showcase its key features, and connect students, staff, and institutions.

## Tech Stack

* React
* Tailwind CSS
* Vite

## Features

* Responsive navigation
* Hero section with waitlist CTA
* How It Works section
* Responsive design for mobile and desktop
* Figma-based UI implementation

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
